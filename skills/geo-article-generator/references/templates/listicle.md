# Template — Listicle (Top N / Best)

Read at Step 5 **only when** genre is **Listicle** (Information Need:
Evaluate / Select under Commercial). Compose from `../retrieval-units.md`.

Listicle is a **Genre**, not a GEO principle and not a Retrieval Unit.

## Skeleton

```text
H1
├── Summary / TL;DR
├── Comparison (Quick Comparison Table)
├── Evidence (Methodology)
├── Decision criteria (How to Choose)
├── #1 … #N item hubs
│   ├── Overview
│   ├── Best For
│   ├── Feature bullets (Key Features)
│   ├── Pros
│   ├── Cons
│   ├── Pricing          ← One Primary Answer: cost only
│   └── Recommendation seed (Why We Picked It)
├── Feature Matrix
├── Pricing Comparison
├── Decision Tree / Recommendation
├── FAQ items
└── Sources
```

## Rules

- Each #N item is a mini entity hub; restate canonical names.
- Pros **and** Cons when materials allow.
- Ranking criterion must be explicit — no silent #1 promo.
- Drop empty sections; map every Step 3 question to a unit (Coverage Check).
- Sources: same two-layer rule as `explainer.md`.

## What not to do

- Default every article to Listicle.
- Promise "Listicle = more GEO traffic."
- Invent competitors or prices to fill N slots.
- Pack pricing + pros + history into one chunk.
