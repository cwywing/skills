# Template — Benchmark

Read when Information Need is **Compare** with **metric-led** evidence
(throughput, accuracy, cost/perf, latency, etc.). Compose from
`../retrieval-units.md`.

## Skeleton

```text
Lead (Summary: what was measured)
├── Evidence (Methodology: setup, versions, date)
├── Feature Matrix / metric Comparison table
├── Per-metric chunks (each metric = One Primary Answer)
├── Recommendation (optional; criterion explicit)
├── FAQ
└── Sources
```

## Rules

- Numbers must be sourced (Step 2). No invented benchmarks.
- One metric per section when results are long — do not bury five KPIs in one
  paragraph.
- Methodology is mandatory for cite-worthy numbers.
