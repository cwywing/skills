# Template — Review (single product)

Read when Information Need is **Evaluate** one product (or Transactional
Decide with pricing focus). Compose from `../retrieval-units.md`.

## Skeleton

```text
Lead (Summary + Definition)
├── Overview
├── Best For / Not For
├── Pros
├── Cons
├── Feature Matrix or Key Features (one primary angle)
├── Pricing
├── Evidence (methodology / testing notes)
├── Recommendation
├── FAQ
└── Sources
```

## Rules

- Pros and Cons both required when materials allow.
- Pricing chunk = cost only (One Primary Answer).
- No adjective stacks without sourced facts.
