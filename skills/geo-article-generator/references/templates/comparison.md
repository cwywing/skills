# Template — Comparison (X vs Y)

Read when Information Need is **Compare**. Compose from `../retrieval-units.md`.

## Skeleton

```text
Lead (Summary: who this comparison is for)
├── Definition of each side (short)
├── Comparison table (shared dimensions)
├── Feature Matrix
├── Pricing (each side — separate chunks if long)
├── Pros / Cons per side (optional)
├── Decision Tree / Recommendation
├── FAQ
└── Sources
```

## Rules

- Define **both** sides; one-sided "we're better" is not citable.
- Shared dimensions must be identical across table and matrix (consistency).
- Each section: One Primary Answer only.
