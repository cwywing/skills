# 框架与语言适配（栈无关）

本 skill **不绑定**某一后端或前端栈。Phase 1 提取脚本提供「按目录扫源码」的辅助清单；默认目录键只是常见约定的**回退值**，必须用 `基础资料.md` 的 `# config` 覆盖成当前仓库真实路径。

**判定：** 材料成败取决于 Phase 2a 选中的真实源码 + Phase 3 说明书，而不是 Phase 1 是否解析出完整方法签名。

**填表示意：** 若干已填好的 `# config` / 选码 JSON 样例在 `assets/demos/`（见该目录 `README.md`）。只对照字段与路径风格，**禁止**把 demo 路径原样写入真实材料。

---

## 配置优先

| 配置键 | 含义 | 填写方式 |
|--------|------|----------|
| 后端项目根目录 | 主业务/服务端代码根 | 相对仓库根，常用 `.` |
| 前端项目根目录 | 独立前端工程根；无则留空 | 相对路径或留空 |
| 后端框架类型 / 前端框架类型 | 仅作备注与适配提示 | 任意标识，如 `spring` / `none` |
| 后端模型目录 | 领域模型 / 实体所在目录 | 相对**后端根** |
| 后端控制器目录 | HTTP/API 入口所在目录 | 相对后端根 |
| 后端服务目录 | 业务服务 / 用例层 | 相对后端根 |
| 后端路由目录 | 路由定义目录（可无） | 相对后端根；无可留空 |

脚本内置回退目录（仅当配置未写时）：`app/Models`、`app/Http/Controllers`、`app/Services`、`routes/api`。这是历史默认值，**不是**对本 skill 适用范围的限定。

## Phase 1 能力边界

| 情况 | 做法 |
|------|------|
| 目录已覆盖且扩展名可被扫描 | 用 `codebase_data.json` 作选码参考 |
| 语言/结构与默认解析器差异大（方法签名对不上） | 接受 models/controllers 偏空；**继续 2a** |
| 单体多语言、多包 monorepo | 根目录填仓库根或子包根；2a 跨包选文件 |
| 仅脚本/桌面/嵌入式 | 把主源码树填进「后端*」一侧；前端数组可 `[]` |

提取脚本当前对部分动态语言的类/表名解析较宽松；非其强项时不要强依赖 Phase 1，把精力放在 2a 选文件与 3 写文档。

## 常见目录映射（示例，非穷尽）

| 栈（示例） | 模型/实体 | 入口层 | 服务/用例 | 路由 |
|------------|-----------|--------|-----------|------|
| FastAdmin + CMS 插件 | `addons/cms/model`、`application/admin/...` | `addons/cms/controller`（非 api） | `addons/cms/library` | 可空；见 `demos/fastadmin-cms/` |
| Spring Boot | `**/entity` / `**/domain` | `**/controller` | `**/service` | 注解路由可空 |
| Django | `**/models.py` | `**/views.py` | `**/services` | `**/urls.py` |
| NestJS | `**/*.entity.ts` | `**/*.controller.ts` | `**/*.service.ts` | 模块路由 |
| Go 模块 | `**/model` / `**/domain` | `**/handler` / `**/api` | `**/service` / `**/usecase` | `**/router` |
| .NET | `**/Entities` | `**/Controllers` | `**/Services` | 可空 |

前端侧示例：页面目录 `pages` / `views` / `screens`；组件 `components`；接口封装 `api` / `services`。单文件组件若含大块样式，生成程序材料时可剔除样式块（脚本对 `.vue` 已做；其他栈手工避免灌水样式）。

`generate_program_identification.py` 按扩展名推断代码围栏；未知扩展名仍整文件读入。

---

## 仅后端 / 仅前端

- 仅后端：`前端项目根目录` 留空；2a 的 `前端文件` 可为 `[]`，接受后端占比偏高。
- 仅前端：把主业务源码填入「后端文件」数组亦可（命名是历史字段，表示「主程序侧」）；或把 BFF/云函数当作后端侧。

## 适配决策示例

```
用户说「给这个 Nest / Django / 桌面客户端做软著」
→ Phase 0 按真实栈改基础资料（目录、编程语言、运行环境）
→ Phase 1 可能摘要偏空 → 加强 2a 按业务手选源码
→ Phase 3 以选中源码与基础资料功能描述为准，勿编造模块
```
