# 软著鉴别材料提交规则（实务摘要）

本 skill 生成程序/文档鉴别材料的 Word 与 **上传用 PDF**。具体以中国版权保护中心 / 当地代办最新要求为准；下列为已固化实务约定（v1.4）。

---

## 需要交付的核心文件

| 材料 | 文件名 | 内容 |
|------|--------|------|
| 程序鉴别材料（Word） | `程序鉴别材料.docx` | 连续源代码全文（校对/存档） |
| 程序鉴别材料（上传 PDF） | `程序鉴别材料.pdf` | **整本**连续源程序，目标 **80～100 页** |
| 文档鉴别材料（Word） | `文档鉴别材料.docx` | 软件说明书全文（校对/存档） |
| 文档鉴别材料（上传 PDF） | `文档鉴别材料.pdf` | **整本**说明书，目标 **≥60 页**（可适当超出） |

**禁止**另存 `程序鉴别材料-全文.pdf` / `文档鉴别材料-全文.pdf`。校对用 Word 即可。

另需用户自行准备：申请表（字段见 `application-form-fields.md`）、身份证明、权利归属证明等——**不在本 skill 自动生成范围内**，结束时提醒用户。

---

## 一致性（强制）

程序和文档中出现的 **权利人署名、软件名称、软件版本号** 须与申请表一致。

本流程要求：程序/文档 **首页 `## 说明`** 固定三行（与 `基础资料.md` 一致）：

```
权利人署名: …
软件名称: …
软件版本号: …
```

页眉标注软件全称与版本号；页脚页码。

---

## 程序鉴别材料（强制）

| 项 | 要求 |
|----|------|
| 页数 | **80～100 页**整本（至少 80，不超过 100） |
| 每页行数 | 宜 **≥50 行**；末页因代码收尾可不足；中间页须达标 |
| 格式 | 上传 **PDF**（`export_identification_pdf.py` 整本导出） |
| 段标题 | `/* ======= {功能名}：{相对路径} ======= */`；**禁止**在标题中写「(二开)」「(二开新增)」 |
| 内容 | 真实业务源码；已排除开源上游原生；无前端时开篇写「由后端程序源代码组成」 |
| 体量校准 | 初选约 **4000～6500** 有效源码行；generate 按 50 行/页估页常偏高；**以 export 实测 80～100 页为准**再加减文件；后端占比 **≥40%**（或纯后端 100%） |

**Contrast — 段标题：**

- Correct：`/* ======= 报价列表页：catalog\view\theme\default\template\account\offer_list.twig ======= */`
- Incorrect：`/* ======= 报价列表页(二开新增)：offer_list ======= */`

> **与官方「前 30 + 后 30」的关系**：版权中心常见表述为「连续前 30 页和连续后 30 页；不足 60 页交全部」。本 skill **交付约定**为整本按 80～100 页控制体量并直接作为上传稿。若当地代办**强制**要求只交前/后各 30 页，再在 Word/PDF 上手工截取；默认不另存全文 PDF。

---

## 文档鉴别材料（强制）

| 项 | 要求 |
|----|------|
| 页数 | **≥60 页**整本；可按材料完整性**适当超出**（建议控制在约 60～80，确有必要时可再厚） |
| 每页行数 | 宜 **≥30 行**（文档标准，不是程序的 50）；末页可不足 |
| 格式 | 上传 **PDF** |
| 文档类型 | 可为程序设计说明书、流程图说明、使用说明等**任一种**描述程序内容/组成/设计/功能/用法的文字资料 |
| 加厚策略 | 优先用真实流程详解 + **流程图 / 时序图 / 状态图 / ER 图 / 界面布局示意**；禁止无意义注水与虚构模块 |

本流程说明书按「背景→蓝图→流程→模块」写厚，并宜含图例。

---

## 形式要求（脚本已尽量满足）

- A4
- 页眉：软件全称 + 版本号
- 页脚：页码
- 源码可读、无大面积无意义填充；敏感信息已过滤（仍需人工抽查）

---

## 告知用户的结束话术要点

1. 上传用 PDF：`程序鉴别材料.pdf`（80～100 页）、`文档鉴别材料.pdf`（≥60 页）
2. Word 可留存校对；**无** `*-全文.pdf`
3. 核对申请表与 `基础资料.md`、首页三行署名一致
4. 法律与审查结果不由本 skill 保证
