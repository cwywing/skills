# 登记系统申请表字段规范（v1.2）

填写 / 改稿 `基础资料.md` 的 `# page3`（及页面上对应项）时必须遵守。  
以中国版权保护中心网上登记常见限制为准；代办另有要求从其要求。

改稿时用 `len(文本)`（Python）或等价方式**数字数**，含标点与空格。

---

## 1. 短字段（均 ≤50 字）

宜写满接近上限，勿只留几个词；细则可放说明书正文。

| 字段 | 上限 | 填写要点 |
|------|------|----------|
| 开发的硬件环境 | ≤50 | CPU/内存/磁盘概要即可 |
| 运行的硬件环境 | ≤50 | 服务器规格 + 联网 |
| 开发该软件的操作系统 | ≤50 | 如 Windows 10 / Windows Server |
| 软件开发环境 / 开发工具 | ≤50 | 语言运行时、DB、框架、IDE；次要工具可省略 |
| 该软件的运行平台 / 操作系统 | ≤50 | 部署 OS + 运行时（按实填写） |
| 软件运行支撑环境 / 支持软件 | ≤50 | 运行时、数据库、Web/中间件等（按实填写） |
| **开发目的** | ≤50 | 解决什么问题、贯通哪些系统；一句说清 |
| **面向领域 / 行业** | ≤50 | 行业 + 场景；可含关键系统名 |

**Correct：** `面向设备售后服务，贯通售后宝工单、金蝶云星空单据与企微审批通知，实现可追溯中转。`（约 40 字）  
**Incorrect：** 两三段痛点叙述塞进开发目的（超 50）  
**Rationale：** 登记页短输入框会拒收；长说明写进说明书。

---

## 2. 软件的主要功能（500～1300 字）

| 项 | 要求 |
|----|------|
| 字数 | **最低 500，最高 1300** |
| 结构 | 按**业务链路**分条（1. 2. 3. …），每项可多句 |
| 禁止 | 只列无关联的模块名；编造未实现能力 |

**Correct：** 工单同步 → 金蝶创单 → 报告闭环 → 企微审批 → 通知 → 文件产出 → 运维…（合计约 800 字）  
**Incorrect：**「含用户管理、权限管理、系统设置」等空模块堆砌  
**Rationale：** 审查看业务是否说清；过短像敷衍，过长超出表单。

---

## 3. 软件的技术特点（标签 + 自填 ≤100）

### 3.1 标签（可多选，可全不选）

登记系统常见标签：

APP、游戏软件、教育软件、金融软件、医疗软件、地理信息软件、云计算软件、信息安全软件、大数据软件、人工智能软件、VR软件、5G软件、小程序、物联网软件、智慧城市软件

- **无强匹配**：可不选  
- **勿硬套**无关标签（如纯后端中转不要勾「小程序」「游戏」）  
- 若按云服务器部署表述，可选「云计算软件」（非必须）

### 3.2 自填文本

| 项 | 要求 |
|----|------|
| 上限 | **≤100 字** |
| 内容 | 架构分层、对接系统、幂等、队列异步、配置化映射、定时/通知等 |

宜写到约 80～100 字，勿过短。

---

## 4. 编程语言（固定列表勾选）

位置：通常在「软件运行支撑环境 / 支持软件」**下方**。

官方列表（只勾选下列名称，逗号分隔写入 `基础资料.md` 的 `编程语言`）：

Assembly language / C / C# / C++ / Delphi/Object Pascal / Go / HTML / Java / JavaScript / MATLAB / Objective-C / PHP / PL/SQL / Perl / Python / R / Ruby / SQL / Swift / Visual Basic / Visual Basic .Net

| 规则 | 说明 |
|------|------|
| 列表内 | 写入 `编程语言` |
| 列表外 | 写入 `其他编程语言`（常见 ≤120 字） |
| 禁止 | 把框架、构建工具、包管理器名填进编程语言（如某 MVC 框架、某前端框架、Composer、npm） |

按**本仓库实际源码**勾选；多种语言则逗号并列列表内项。示例仅作格式参考：`Java,JavaScript,SQL` 或 `HTML,JavaScript,PHP,SQL` 或 `Python,SQL`——以材料中出现的语言为准。

## 5. 与鉴别材料首页的一致性

申请表中的 **著作权人 / 软件全称 / 版本号** 必须与程序、文档鉴别材料首页说明三行完全一致：

```
权利人署名: {著作权人}
软件名称: {软件全称}
软件版本号: {版本号}
```

详见 `content-redaction.md`、`submission-rules.md`。
