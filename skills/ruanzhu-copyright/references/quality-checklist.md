# 交付前质量清单

在宣告「软著材料已生成」之前，逐项核对。未勾选完不得宣称完成。

字数与勾选细则见 `application-form-fields.md`；提交规则见 `submission-rules.md`。

---

## 目录与配置

- [ ] `基础资料.md` 存在且无「（必填）」占位
- [ ] 已填写 **`文档类型`** 与 **`有人机界面`**，二者一致，并与软件实际形态一致
- [ ] 名称含品牌/专名时，已从模板生成 `软件名称说明.md` 草稿或确认有商标证（提醒用户签章上传）
- [ ] 短字段（硬件环境、开发工具、运行平台、支撑软件、**开发目的**、**面向领域**）**均 ≤50 字符**，宜近上限
- [ ] `软件的主要功能` 在 **500～1300** 字（业务链路分条）
- [ ] `软件技术特点`：标签可选（勿硬套）+ 自填 **≤100** 字
- [ ] `编程语言` 均在官方列表内；框架未误填；`其他编程语言` 仅列表外
- [ ] `后端/前端项目根目录` 为相对路径（推荐 `.`）；**说明书 MD 中无本机绝对路径**
- [ ] `md素材/` 下产物齐全
- [ ] 已执行 `redact_materials.py` → `md2docx.py` → `export_identification_pdf.py`
- [ ] **无** `*-全文.pdf` 残留

## 程序鉴别材料

- [ ] 存在 `core_business_files.json`，路径均为相对路径
- [ ] `分类` 为功能名，**不含**「(二开)」「(二开新增)」等标注
- [ ] 存在 `program_identification-1.md` 与 `-2.md`
- [ ] 段标题格式为 `分类：相对路径`（含路径分隔符）
- [ ] 首页说明含 **权利人署名 / 软件名称 / 软件版本号**（与申请表一致）
- [ ] 无前端时开篇为「由后端程序源代码组成」，非虚假「前后端组成」
- [ ] 前端单文件组件材料中无大块样式灌水（如 `.vue` 的 `<style` 应由脚本剔除；其他栈抽查避免纯 CSS 占页）
- [ ] `基础资料` 中的框架/语言/目录已按**当前项目**填写，未照抄模板示例栈
- [ ] 有效源码体量支撑 PDF **80～100 页**（约 4000～6000+ 行量级）；后端占比 ≥ 40% 或纯后端 100%
- [ ] 基于开源框架时已排除上游原生代码（见 `fork-detection.md`）
- [ ] 抽查无明文密码 / APP_KEY / JWT_SECRET
- [ ] 导出 MD/docx/PDF 中无 `C:/Users`、`/home/` 等绝对路径；示例人名已脱敏（若曾出现）

## 文档鉴别材料

- [ ] 存在至少 3～4 个 `document_identification-*.md`
- [ ] **结构顺序正确**：背景 → 蓝图 → 流程详解 → 模块对照
- [ ] 背景含痛点/目标/边界；流程含触发/步骤/规则/结果
- [ ] 宜含流程图 / 时序图 / 状态图 / ER 图等图例（增加可读性与页数）
- [ ] **有人机界面**：已嵌真机截图；概述后有总览图（前 30 页可见）；流程覆盖申请表主要功能；每图 3～5 句；无【缺图】、非设计稿/AI/ASCII 冒充；复杂系统约 15～30 张（见 `rejection-hotspots.md`）
- [ ] 打开 Word/PDF：截图是完整界面，不是细黑线（固定行距压扁）；脚本报告插图高度约 7～17cm
- [ ] 截图内可见名称/版本能对上申请表，或图注写明「安装包显示名 / 构建号」（不要把标题栏称作申请表全称）
- [ ] 图注与该张 PNG 可见内容一致；打码处已说明，未写「未做任何加工」
- [ ] 上传 PDF 体积可传（截图已压长边，不是数十 MB 原图直嵌）
- [ ] 抽一页代码围栏示意图：汉字和框线可读，不是一片点
- [ ] 同一 PNG 未在三个章节全量重复粘贴
- [ ] **无图形界面**：未虚构 UI；有结构/时序图
- [ ] 全称含品牌/音译词时已提醒用户准备《软件名称说明》（模板草稿）或商标证
- [ ] 模块章后置，且能对应到流程
- [ ] **首页说明**含权利人署名/软件名称/版本号；**其余正文**默认不散落单位全称
- [ ] 模块/表名与 `codebase_data.json` 可对上，无虚构大模块
- [ ] 无「TODO」「（必填）」「lorem」
- [ ] PDF 页数 **≥60**（可适当超出）；勿无意义注水

## Word / PDF 成品

- [ ] `程序鉴别材料.docx`、`文档鉴别材料.docx` 已生成且非空壳
- [ ] 页眉含软件全称 + 版本号；有页码；A4
- [ ] 已生成上传用 `程序鉴别材料.pdf` 与 `文档鉴别材料.pdf`（整本）
- [ ] **无** `程序鉴别材料-全文.pdf` / `文档鉴别材料-全文.pdf`
- [ ] 程序 PDF：**80～100 页**；中间页约 **≥50 行**/页（以 export 实测为准，勿只信 generate 估页）
- [ ] 文档 PDF：**≥60 页**；中间页约 **≥30 行**/页（不足则加 `-5`～`-7` 后重导）
- [ ] `core_business_files.json` 含三次审查记录；独创业务优先、样板未占主导
- [ ] 抽查 PDF 首页三行署名与申请表一致；无绝对本地路径
- [ ] 补正只改点名项时，未点名的程序/文档稿未被本次导出覆盖

## 提交提示（告知用户）

正式登记上传：**程序 PDF**（80～100 页整本）+ **文档 PDF**（≥60 页整本）。详见 `submission-rules.md`。  
申请表身份材料由用户自行准备。
